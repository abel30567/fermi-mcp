# Worker Package

The main Cloudflare Worker that serves as the MCP server.

## Key Files

- **wrangler.jsonc** — Generated by `bootstrap.sh`. Contains account-specific resource IDs. Gitignored.
- **wrangler.template.jsonc** — Template with `__PLACEHOLDER__` tokens. Committed.
- **vitest.config.ts** — Test configuration using Cloudflare Workers pool
- **vitest.contract.config.ts** / **wrangler.test.jsonc** — MCP contract project: boots the real worker entry and drives it over `/mcp` via `SELF.fetch` (`test/contract/`)
- **worker-configuration.d.ts** — Auto-generated type definitions for Worker bindings

## Subdirectories

- **src/** — Application source code
- **migrations/** — D1 SQL migrations (applied in order)
- **seeds/skills/** — Built-in skill templates loaded on first deploy
- **public/** — Static assets served by the Worker
- **test/** — Vitest test files

## Commands

```bash
bun run dev           # Local dev server
bun run test          # Unit + contract test projects
bun run test:contract # Contract tests only (real worker over MCP)
bun run migrate:local # Apply migrations locally
bun run migrate:remote # Apply migrations to production D1
```
